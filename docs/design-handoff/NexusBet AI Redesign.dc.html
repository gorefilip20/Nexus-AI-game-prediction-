Design rationale

The point of view: this is a research terminal, not a tipster site, so restraint is the brand. One accent (green) does all the signalling; everything else is set in ink-on-charcoal, flat and ruled rather than boxed. Rows and rules replace the equal-weight card grid, so a Champions League tie can read bigger than a third-tier one and a 200-fixture day still scans.

Conventions broken on purpose: with a single accent available, colour is reserved for the settled win and the live indicator — nothing else earns it. A loss or a pending pick is told through weight, an icon and an explicit label, never a second colour. "High confidence" is a bold row and a small flush tag, not another glowing badge. Chat is a flush, ruled message list, not rounded bubbles. Zero corner radius, Archivo throughout, tabular figures on every number.

Every "not yet" state — an empty tracker, an empty lounge, a day with no fixtures — is designed as its own considered screen rather than a grey box, because a new deployment shows these states first.
